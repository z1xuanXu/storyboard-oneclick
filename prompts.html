Prompt Library

提示词示例与写法

这页展示如何把“一个故事”写成可执行的图像生成语言。重点不是堆形容词，而是稳定角色、场景、物品和镜头意图。

Principles

四个写作原则

01

先定参考图

主角、家、办公室、关键道具先生成，再在镜头里引用，避免每个镜头像不同作品。

02

一镜一任务

单帧图只表达一个镜头目标：接电话、翻找、确认没丢、听见低语。

03

明确画面结构

写清景别、视角、主体位置、前景背景、光线方向和画面留白。

04

限制跑偏内容

恐怖题材尤其要写“不出现血腥”“不出现明显怪物”，让氛围克制。

Reference Prompts

参考图提示词

REF01 主角

30多岁公司职员，略疲惫，深色西装外套，白衬衫，黑发，眼下有轻微黑眼圈，普通都市男性，不夸张恐惧表情。

REF02 办公室工位

夜色将近的开放式办公室，显示器、键盘、文件夹、一次性咖啡杯，冷白顶灯，窗外城市灯光。

REF03 主角家

普通单身公寓，玄关鞋柜、钥匙盘、客厅沙发、半开的卧室门，暖黄灯但阴影很重。

REF04 那把钥匙

一把普通银色门钥匙，旧钥匙环上有磨损，孤零零放在暗色木桌，强烈侧光，投下细长阴影。

Frame Prompt Formula

单帧图提示词公式

单帧图提示词适合写得具体：画面比例、主体、动作、构图、视角、光线、道具、质感都要落地。

类型比例 → 场景时间 → 主体动作 → 构图景别 → 视角镜头 → 光线色调 → 道具细节 → 质感限制
现实主义悬疑短片单帧，16:9，傍晚开放式办公室，
冷白顶灯，窗外城市灯光，30多岁男职员独自坐在工位电脑前，
深色西装外套白衬衫，桌面有文件夹、咖啡杯、键盘和手机，
构图为中远景，轻微俯视，人物偏画面右侧，空间空旷，
冷色调，低对比胶片颗粒，真实电影质感。

Shot Examples

镜头提示词示例

S04 电话内

极近特写，男主角耳边贴着手机，画面只包含耳朵、手机边缘和一只紧张的眼睛，眼神突然凝住，办公室冷光，背景完全虚化，构图压迫。

S10 翻找卧室

卧室中近景，男主角半蹲在床边翻床头柜和衣柜，衣物被拉出，抽屉半开，暖黄灯下阴影很深，构图偏斜，轻微广角。

S20 结尾道具

暗色木桌或玄关钥匙盘上有一处明显钥匙空位，细小灰尘轮廓和金属挂钩形成视觉中心，侧光投下长阴影。

Image-to-Video Prompt

图生视频提示词

图生视频提示词重点写“怎么动”：运镜速度、焦点变化、主体动作、光线变化和节奏。不要把静态画面提示词完整复制一遍。

镜头从办公室走道缓慢推向主角工位，速度很慢，
冷白灯轻微闪烁，画面保持现实主义悬疑质感，
城市窗光在背景虚化，不出现夸张恐怖元素。

Prompt Checklist

生成前检查

  • 是否写明画幅，例如 16:9。
  • 是否有统一角色参考图。
  • 是否有统一场景参考图。
  • 关键道具是否提前生成。
  • 同一场景是否使用同一组参考图。
  • 是否写了限制项防止画面跑偏。

Prompt examples are educational. Adapt them to your own story structure before generation.
